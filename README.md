# 🚀 Vendico: MERN Stack E-Commerce Platform

> **Your Gateway to Online Retail Success!** 🛒✨

Vendico is a full-stack e-commerce solution built using the powerful **MERN Stack** (MongoDB, Express.js, React.js, Node.js). 
It provides a complete, scalable, and responsive foundation for an online store featuring:  
🔒 **Authentication**, 🛍️ **Product Browsing**, 🛒 **Shopping Cart**, 🛒 **Order Processing**, and 💳 **Payment Integration**.

Perfect for entrepreneurs 🚀, startups 🌱, or businesses 🏢 aiming to **build a successful online presence**.

---

## 🛠️ Setup Guide

### 📋 Prerequisites
- **Node.js** and **npm**: [Install Node.js](https://nodejs.org/)
- **MongoDB**: [Install MongoDB](https://www.mongodb.com/try/download/community) or use [MongoDB Atlas](https://www.mongodb.com/atlas)
- **Git**: [Install Git](https://git-scm.com/)

---

### 🧩 Installation Steps

#### 1. 📥 Clone the Repository
```bash
git clone https://github.com/Sai-guru/MERN_eCommerce.git
cd MERN_eCommerce
```

#### 2. 🔧 Backend Setup
```bash
cd backend
npm install
```

Create a `.env` file inside `backend/` with:
```plaintext
PORT=5000
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_random_jwt_secret
PAYPAL_CLIENT_ID=your_paypal_client_id
```

#### 3. 🎨 Frontend Setup
```bash
npm create vite@latest
cd frontend
npm install
npm run dev

 =>Main : use nodemon (npm i nodemon) in backend folder for live flow of our backend
#### 4. 🚀 Running the Application

- **Backend:**
  ```bash
  cd backend
  npm start
  ```

- **Frontend:**
  ```bash
  cd frontend
  npm start
  ```

#### 5. 🌐 Access Your App
Go to [http://localhost:3000](http://localhost:3000)
